# 更新日志

## v1.6.0 — 2026-10-25

- 数据目录改到 `%LOCALAPPDATA%\通知助手`，不再在 exe（桌面）旁边生成 `settings.ini` / `data` / `logs`；
- 首次运行新版时自动迁移旧版数据；
- 主界面新增「打开数据目录」入口。

## v1.5.0 — 2026-10-24

- 移除“极速模式”开关；
- 间隔设置成为唯一发送节奏来源：按“两条消息开始发送之间的周期”调度；
- 低于 1 秒时自动压缩单条等待，1 秒及以上恢复普通流程；
- 修复间隔设置与实际发送节奏不一致的问题。

## v1.3.0 — 2026-10-24

- 发送间隔支持两位小数（0.01 ~ 3600 秒）；
- 间隔数字支持点击输入；
- 快捷值：0.1 / 0.25 / 0.5 / 1 / 5 秒。

## v1.2.0 — 2026-10-24

- 目标窗口支持微信（`WeChat.exe` / `Weixin.exe`）；
- 新增三字经模式（20 条「是不是 / 对不对」交替）；
- 拦截 `@所有人` / `@everyone`。

## v1.1.0 — 2026-10-24

- 暖白纸感 UI 重做，移除深色渐变 / 霓虹风；
- 新增淡入、悬停、开关/分段滑动、进度条、状态呼吸、迷你窗脉冲动画；
- 修复间隔控件、设置行拥挤和底部文字裁切问题。

## v1.0.0 — 2026-10-24

- 首个版本：QQ 群通知，TXT 导入，键鼠模拟发送，目标窗口校验，日志。
